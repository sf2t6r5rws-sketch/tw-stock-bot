# 台股盤後分析機器人

每個交易日晚上 7 點左右自動執行，並把結果傳到你的 Telegram：

1. **檢查持股**：停損價、目標價、單一個股與主動部位上限、主動部位虧損、整體回撤分級警戒（10% / 20%）
2. **觀察清單**：股價跌到你設定的觀察價時通知
3. **全市場掃描**：從上市櫃全部股票篩出符合條件的候選名單

休市日不會發送訊息。全程免費，也不需要會寫程式。

---

## 第一次設定（約 20 分鐘，建議用電腦）

### 步驟 1：建立 Telegram 機器人

1. 在 Telegram 搜尋 **@BotFather**，按「開始」。
2. 傳送 `/newbot`，依指示輸入機器人名稱，再輸入一個以 `bot` 結尾的帳號名稱，例如 `my_tw_stock_bot`。
3. BotFather 會回覆一串**金鑰（token）**，格式像 `123456789:ABCdef...`，先複製保存。**不要給別人看**。
4. 點 BotFather 給你的連結進入你的機器人，隨便傳一句話給它，例如「hi」。
5. 用瀏覽器打開下面網址，把 `<金鑰>` 換成剛剛的 token：
   `https://api.telegram.org/bot<金鑰>/getUpdates`
6. 在頁面中找到 `"chat":{"id":` 後面的數字，這就是你的 **chat id**，複製保存。
   （如果頁面只有 `"result":[]`，再傳一次訊息給機器人，然後重新整理頁面。）

### 步驟 2：建立 GitHub 儲存庫

1. 到 github.com 註冊帳號並登入。
2. 右上角「+」→「New repository」。
3. Repository name 填 `tw-stock-bot`，選 **Private（私人）**，按「Create repository」。
4. 在新頁面點「uploading an existing file」，把壓縮檔解開後的這幾項拖進去：
   `bot` 資料夾、`state` 資料夾、`reports` 資料夾、`config.yaml`、`requirements.txt`、`README.md`
5. 按下方綠色「Commit changes」。

### 步驟 3：建立排程檔（這個要手動建）

`.github` 是隱藏資料夾，用拖的常常傳不上去，所以直接在網頁上建立：

1. 在儲存庫首頁點「Add file」→「Create new file」。
2. 檔名欄位輸入：`.github/workflows/daily.yml`（打到 `/` 時會自動變成資料夾，這是正常的）
3. 打開壓縮檔裡的 `.github/workflows/daily.yml`，把內容全部複製貼上。
   （Mac 看不到這個資料夾的話，在 Finder 按 `Command + Shift + .` 顯示隱藏檔。）
4. 按「Commit changes」。

### 步驟 4：放入 Telegram 金鑰

1. 儲存庫上方點「Settings」→ 左側「Secrets and variables」→「Actions」。
2. 按「New repository secret」，新增兩個：
   - Name：`TELEGRAM_BOT_TOKEN`，Secret：步驟 1 的金鑰
   - Name：`TELEGRAM_CHAT_ID`，Secret：步驟 1 的 chat id

### 步驟 5：填你的持股，然後試跑

1. 回到儲存庫首頁，點 `config.yaml` → 右上角鉛筆圖示，把範例持股改成你自己的，再按「Commit changes」。
2. 點上方「Actions」，如果出現提示就按綠色按鈕啟用。
3. 左側點「每日盤後分析」→ 右側「Run workflow」→ 再按一次綠色「Run workflow」。
4. 等 3 到 5 分鐘，Telegram 應該會收到日報。之後每個交易日都會自動執行。

## 平常怎麼用

所有設定都在 `config.yaml`，在 GitHub 網頁上點鉛筆就能改，手機也可以。

| 發生什麼事 | 要改什麼 |
| --- | --- |
| 買進或賣出 | 更新 `holdings` 的股數和平均成本，並更新 `cash` |
| 存錢進投資專戶 | `cash_flows` 加一筆正數，並把 `cash` 加上這筆錢 |
| 從專戶提領 | `cash_flows` 加一筆負數，並把 `cash` 扣掉這筆錢 |
| 想改停損價或目標價 | 改該檔持股的 `stop_loss`、`target` |
| 想追蹤某檔股票 | 加進 `watchlist`，填 `buy_below` 觀察價 |
| 想改掃描條件 | 改 `scan` 底下的數字；不要某個條件就在那行最前面加 `#` |

**cash_flows 很重要**：存錢和提領一定要記，程式才能把資金進出和投資損益分開，回撤才會算對。記過的不要刪。

## 日報怎麼看

- **需要處理**：觸發的規則都列在這裡。沒有東西就代表今天不用做任何事。
- **組合狀況**：「淨值」從 100 開始計算，已排除存錢和提領的影響，可以拿來和 0050 比較。
- **市場掃描**：符合所有條件的股票，依殖利率由高到低排序。這只是研究清單，依計畫書第五章，寫好買進理由和出場條件之後才可以下單。

## 注意事項

- 這是**盤後**分析，不是即時監控。盤中停損請用券商的停損條件單，由券商主機盯盤比較可靠。
- 主動部位的虧損是**相對成本**計算，和計畫書寫的「從最高值」略有不同：如果主動部位先漲後跌，這裡會比計畫書的算法晚觸發，請在每月審查時自己再看一次。
- 每日股價、本益比、殖利率來自證交所和櫃買中心的公開資料；均線和均量來自 Yahoo Finance。Yahoo 偶爾抓不到資料，這時日報的「系統提醒」會說明，候選名單也會少掉技術面篩選。
- GitHub 的排程有時會延遲幾分鐘到一小時，這是正常的。
- 私人儲存庫每月有免費執行額度，這個程式每天跑幾分鐘，用量遠低於上限。
- 一直沒收到訊息：到「Actions」看最近一次執行，紅色叉叉點進去可以看到錯誤原因。
